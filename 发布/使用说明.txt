掠夺者控制台 (Predator Control) — 使用说明
================================================

适用机型：Acer Predator PHN16-72 / Helios Neo 16（2024 款，PredatorSense X 系列）
已在：i9-14900HX + RTX 4060 Laptop 上适配


一、为什么 PredatorSense 有时读不到温度
------------------------------------------------
PredatorSense 读取 CPU/GPU 温度和风扇转速，走的是 Acer 私有 ACPI 接口
（root\WMI → AcerGamingFunction），这个接口受权限保护，只有 SYSTEM /
管理员权限才能访问。

普通权限访问时，Windows 不会明确报"权限不足"，而是返回
0x80070057「无效的方法参数」——于是上层软件就表现为"识别不到硬件"。
另外 PredatorSense 自身启动顺序早于 Acer 后台服务时，也会出现读不到的情况。

本程序用同样的官方接口，但做了三件事来避免这个问题：
  1. 启动即申请管理员权限；
  2. 每秒重试一次读取，接口恢复后自动显示数据（不会一直空着）；
  3. 每次读取失败都会在底部状态栏显示具体原因，而不是静默失败。


二、功能
------------------------------------------------
· CPU 温度 / GPU 温度 / CPU 风扇 / GPU 风扇 实时显示
  （风扇以实际转速 RPM 为准——自动模式下固件不回传占空比，
   百分比读数恒为 0，只有手动/曲线模式才会给出真实占空比）
· 180 秒温度趋势曲线
· GPU 功耗、频率、占用率（来自 NVIDIA 官方接口）
· 风扇四种模式：
    自动  —— 交还硬件自动调速（等同于 PredatorSense 的"自动"）
    最大  —— 双风扇全速（等同于"最大/Turbo"）
    手动  —— 自己拖滑块指定转速百分比
    曲线  —— 按温度自动调速，曲线可拖动编辑
· 可最小化到系统托盘，托盘提示实时显示温度
· 退出程序时自动把风扇交还"自动"模式


三、运行要求
------------------------------------------------
· Windows 10 / 11 x64
· 首次运行会弹出 UAC，请点"是"（不带管理员权限只能看界面，读不到数据）
· 单文件绿色程序，无需安装，无需 .NET 运行库


四、重要提示
------------------------------------------------
1. 手动 / 曲线模式下，请不要同时使用 PredatorSense 的风扇设置，
   两边会抢控制权（表现为转速被改回去）。二选一即可。
2. 退出程序会自动恢复"自动"模式，不会把风扇锁死。
3. 风扇转速范围建议不要低于 25%，过低在满载时可能过热降频。
4. 曲线模式下带 3℃ 回差，避免转速频繁抖动。


五、遇到读不到数据怎么办
------------------------------------------------
点右上角「诊断」按钮 → 「打开日志文件」。
日志会记录每一步接口调用返回的原始值，可以直接判断是权限问题、
接口不支持，还是传感器 ID 需要按机型调整。

日志位置：%LOCALAPPDATA%\PredatorControl\diagnostics.log


六、后台运行与资源占用（实测）
------------------------------------------------
测试环境：i9-14900HX（32 线程）/ RTX 4060 Laptop / Windows 11

· 主界面可见时：CPU 约占单核 0.6% ~ 0.9%（占整机约 0.02%），
  内存约 150 MB，线程 12 个
· 最小化到托盘后：CPU 约 0.05%（几乎可以忽略），内存稳定在约 140 MB
  且不再增长；长期挂着建议用托盘状态

数据采集全部在进程内完成（Acer ACPI 接口 + NVIDIA 驱动接口），
不会反复启动外部程序，也不会有窗口一闪而过。

命令行参数：
  PredatorControl.exe --tray      启动后直接缩到托盘（适合设为开机自启）
  PredatorControl.exe --demo      演示模式，用模拟数据展示界面
